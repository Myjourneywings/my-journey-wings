# My Journey Wings Travel Services — dashboard UI starter

This is a responsive front-end prototype based on the MAARKS dashboard screenshots supplied in the conversation, rebranded for My Journey Wings Travel Services.

## Run locally
Open `index.html` in a modern browser. No build step is required.

## Demo behavior
- Sign-in form accepts any valid email and non-empty password (front-end demonstration only).
- Sidebar navigation switches between the dashboard and module placeholder pages.
- Search filters the sample rows in the module table.
- Add New and View controls show demo messages.

## Important before production
This is a UI prototype, not a production clone. It does not connect to the original MAARKS system, database, APIs, or authentication. Replace sample dashboard numbers and records with authorized company data. Implement secure server-side authentication, roles/permissions, audit logs, validation, and database-backed CRUD before launch. Only reproduce functionality you own or are authorized to use.
